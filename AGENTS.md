# LUZVE — Instrucciones para agentes de programación

## Contexto del proyecto

LUZVE es una plataforma web comunitaria para conocer y reportar el estado eléctrico de diferentes zonas de Venezuela.

El MVP se enfocará inicialmente en Valencia, Carabobo.

La especificación funcional completa se encuentra en:

LUZVE_SPEC.md

## Principios de desarrollo

- Mantener el proyecto sencillo.
- Priorizar claridad y mantenibilidad sobre complejidad.
- No introducir dependencias innecesarias.
- No implementar funcionalidades fuera del alcance del MVP sin autorización.
- Mantener una arquitectura apropiada para un proyecto pequeño que pueda crecer posteriormente.
- Priorizar una experiencia de usuario rápida y sencilla.
- La aplicación debe poder ser utilizada sin registro obligatorio.

## Desarrollo para este proyecto

El propietario del proyecto tiene conocimientos básicos de programación.

Por esta razón:

- Explicar brevemente los cambios importantes.
- Evitar soluciones innecesariamente complejas.
- Cuando sea posible, preferir código claro sobre código excesivamente abstracto.
- No ocultar errores importantes.
- Proporcionar instrucciones claras para ejecutar y probar los cambios.

## Calidad

Antes de considerar terminada una funcionalidad:

- Ejecutar las pruebas disponibles.
- Verificar que la aplicación pueda iniciarse correctamente.
- Revisar errores relacionados con la funcionalidad modificada.
- No modificar funcionalidades no relacionadas con la tarea.

## Git

- Trabajar sobre la rama principal existente salvo que se indique lo contrario.
- Realizar commits claros y descriptivos cuando corresponda.
- No realizar cambios destructivos sin autorización.
- No eliminar archivos o funcionalidades existentes sin una razón relacionada con la tarea.

## Producto

No asumir que una funcionalidad es necesaria solamente porque sea técnicamente posible.

La prioridad es:

1. Resolver el problema del usuario.
2. Mantener la experiencia sencilla.
3. Validar el MVP.
4. Añadir complejidad solamente cuando exista una necesidad real.
